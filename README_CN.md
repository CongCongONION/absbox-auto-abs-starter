# Auto ABS 现金流建模与信用压力测试（中文说明）

英文主 README 见 [README.md](README.md)。本文件是 v2 的中文摘要；
v1 的中文说明保留在 git 历史中。

## v2 改了什么（2026-11-11）

针对一次外部评审指出的问题做了系统性修复：

1. **资产模型换成真实摊还贷款**：v1 用 `Installment` 代表线（按原始余额收
   flat fee），且三个分段的起始日/seasoning 不一致，导致 pool 第一期余额
   从 $100M 直接掉到 $92.82M、其中 $4.86M 无法用现金流列解释。v2 改为
   AbsBox 的 `Mortgage` Level 型资产（按未偿余额计息、等额月供摊还——
   汽车贷款的真实形态），三个分段统一在 cutoff 日（2025-12-01）originate，
   池子期初精确等于 $100,000,000。
2. **分段差异化假设**：prime / near-prime / subprime 各用自己的
   CDR/CPR/Recovery/Lag（经 ByPoolId 子池实现；ByIndex 形式经实测不被
   0.50.2 引擎接受）。
3. **逐期对账**（`src/reconciliation.py`）：池恒等式
   期初 − 计划还本 − 提前还款 − 违约 = 期末，每期残差 ≤ 3e-08；
   债券恒等式、损失分配顺序、账户守恒全部 PASS。压力情景账户期末
   $1,222.98 是最终分配日之后收到的回收款（2031-05-31），已标注说明。
4. **Break-even CNL**（`src/breakeven.py`，二分法缩放 CDR 倍数）：
   E 档首次本金损失在 ≈3.85× base CDR 处，池累计净损失 $8.64M（8.64%）；
   B 档在 ≈5.64× 处，CNL $12.07M（12.07%）。
5. **定价改 XIRR**（真实日期折现，替代等间隔月 IRR）。

## v2 核心结果（引擎实际运行）

| 情景 | 池累计净损失 | A WAL / XIRR | B WAL / XIRR | E XIRR | 各档本金损失 |
|---|---:|---:|---:|---:|---|
| Base | $2.43M | 1.64y / 5.12% | 3.73y / 7.76% | 25.08% | 无 |
| Optimistic | $1.02M | 1.55y / 5.12% | 3.58y / 7.76% | 28.67% | 无 |
| Stress | $7.49M | 1.83y / 5.12% | 4.14y / 7.76% | 9.32% | 无 |

结论与 v1 不同，原因正是资产模型变真实了：池 WAC ≈ 9.8%，全周期利息
收入约 $21M，excess spread 很厚——三个情景的损失全部被利差吸收，
任何一档都没有本金损失。权益档的风险表现为**剩余现金流被压缩**
（optimistic $10.10M → base $8.67M → stress $2.65M），而不是本金亏损；
本金什么时候开始亏，看 Break-even CNL。敏感性网格里固定 CDR、提高
CPR 仍会单调压缩 E 的剩余分配（利差被提前还款掏薄），与 v1 的方向
一致且这次是隔离变量的结果。
